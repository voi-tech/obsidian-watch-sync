# Security policy

## Supported versions

Security fixes are provided for the latest released version of Stremio Sync.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed secret.

Use GitHub's **Report a vulnerability** form in the repository's Security tab:

https://github.com/voi-tech/obsidian-stremio-sync/security/advisories/new

Include the affected version, impact, reproduction steps, and a minimal proof of concept. Redact Stremio and TMDB keys, account data, vault paths, and note contents. You should receive an acknowledgement within seven days.

The plugin does not collect telemetry. Please do not include `data.json`, `cache.json`, generated `main.js`, or an unredacted vault export in a report.
